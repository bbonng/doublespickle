시트는 A:반 / B:이름 / C:성별 / D:비고 구조 그대로면 됩니다.
⚙️ 시트에서 공유 → 일반 액세스 → "링크가 있는 모든 사용자(뷰어)"로 한 번 바꿔주세요. 주소는 이 기기에 저장돼 다음부턴 자동으로 불러옵니다.
🚫 D열(비고)에 특수 · 제외를 적은 학생은 평가에서 상시 제외됩니다. 결석은 시트를 건드리지 말고 아래에서 탭으로 빼세요.
실제 사용할 코트 수예요. 경기가 코트보다 많으면 같은 코트에서 여러 경기(1코트/1경기, 1코트/2경기…)로 돌아갑니다.
② 결석한 학생 이름을 탭하면 오늘만 빠집니다(다음에 다시 켜면 전원 복귀). 회색은 제외, 줄 그어진 잠금은 비고 상시제외.
